Put the lyrics here as plain text (UTF-8), one file per song:

  goodness-of-god.txt           (tab 2 of the "P&W Lyrics" Google Doc)
  love-can-make-us-brave.txt    (tab 1 of the "P&W Lyrics" Google Doc)

How: in Google Docs open the tab, then File > Download > Plain text (.txt),
and rename the file as above.

Rules the page follows when it reads the file:
  - The first line is treated as the song title and is skipped.
  - A line such as "Verse", "VERSE 2:", "CHORUS 1", "Bridge", "Outro" or "Chapter 2:"
    becomes a section heading.
  - A line with Chinese then English on the same line is split into two lines.
  - A line that is only Chinese or only English is shown as is.
  - Blank lines are ignored.
