Fonts
=====
Titles use "Brittany Signature". It is not on Google Fonts, so it is not included here.
If you have the font file (check its licence allows web use), put it in this folder with these exact names and the site uses it automatically:
    BrittanySignature.woff2      (preferred, small)
    BrittanySignature.ttf        (fallback)
Until then the titles use Allura, a free signature-style script.

Body text uses Montserrat Bold, loaded from Google Fonts. Chinese text uses Noto Sans SC (bold) and Noto Serif SC (titles).
